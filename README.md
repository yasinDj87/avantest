# AVAN 2.0 — فروشگاه نمایشی ساعت

این پروژه یک قالب فرانت‌اند استاتیک با HTML، CSS و JavaScript است.

## امکانات
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- دسته‌بندی، جست‌وجو، مرتب‌سازی و فیلتر قیمت
- نمایش جزئیات محصول و علاقه‌مندی‌ها
- سبد خرید با تغییر تعداد و ذخیره در مرورگر
- پنل مدیریت نمایشی برای افزودن، حذف و ویرایش قیمت محصولات
- ثبت سفارش آزمایشی و نمایش آن در پنل مدیریت

## جایگزینی فایل‌ها
فایل‌های `index.html`، `style.css` و `script.js` را در ریشه مخزن GitHub جایگزین نسخه قبلی کنید و Commit بزنید. اگر پروژه به Vercel متصل است، پس از Push شدن تغییرات، انتشار جدید به‌صورت خودکار شروع می‌شود.

## نکته مهم
این نسخه همچنان فقط فرانت‌اند نمایشی است. اطلاعات در مرورگر فعلی و با `localStorage` ذخیره می‌شوند. پنل مدیریت احراز هویت امن ندارد و برای مدیریت واقعی چندکاربره مناسب نیست. ثبت سفارش، پرداخت آنلاین، موجودی مشترک، ارسال ایمیل و اتصال به درگاه پرداخت پیاده‌سازی نشده‌اند. برای فروش واقعی به بک‌اند، پایگاه داده، احراز هویت امن و درگاه پرداخت نیاز است.
