# فروشگاه نمایشی ساعت لوکس آوان

این یک قالب استاتیک HTML/CSS/JS و آماده انتشار روی Vercel است.

## اجرای محلی
فایل `index.html` را با مرورگر باز کنید.

## انتشار روی Vercel
1. این پوشه را در یک مخزن GitHub آپلود کنید.
2. وارد https://vercel.com شوید و با GitHub ثبت‌نام/ورود کنید.
3. از داشبورد Vercel گزینه Add New → Project را بزنید.
4. مخزن GitHub را Import کنید.
5. چون پروژه HTML ساده است، Framework Preset را روی Other بگذارید.
6. Build Command و Output Directory را خالی بگذارید.
7. روی Deploy کلیک کنید.

## نکته مهم
این نسخه یک قالب نمایشی فرانت‌اند است. سبد خرید واقعی، پرداخت آنلاین، پنل مدیریت، موجودی و ثبت سفارش هنوز پیاده‌سازی نشده‌اند. نام‌ها، قیمت‌ها و محصولات نمونه‌اند.
