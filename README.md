# Aurelia & Cie — Luxury Watch Store

Static multi-page site. Upload the **contents of this folder** to the root of your GitHub repo. Vercel needs no extra settings.

## Pages

| URL | File |
|-----|------|
| `/` | `index.html` — Homepage |
| `/collections` | `collections.html` — Collections |
| `/product` | `product.html` — Product detail (Chrono Tourbillon) |
| `/daytona` | `daytona.html` — Rolex Cosmograph Daytona |
| `/cart` | `cart.html` — Private Vault shopping cart |
| `/checkout` | `checkout.html` — Checkout / allocation |
| `/dashboard` | `dashboard.html` — Collector dashboard |

## Deploy

1. Put all files in the **root** of the GitHub repo (not inside a subfolder)
2. Vercel → Import repo → Deploy

`vercel.json` handles clean URLs automatically.
